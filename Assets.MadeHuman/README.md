# Assets.MadeHuman

This directory is the portable, fully baked glTF release of the MIT-licensed
Microsoft Rocketbox source assets for MadeHuman.NET. It is generated by the
`top-5/madehuman` Rocketbox pipeline; source FBX/TGA files remain under
`Assets/`, unchanged.

The intended layout is:

```text
Assets.MadeHuman/
  catalog.json
  animation-manifest.json
  Avatars/<source category>/<avatar>/<avatar>.glb
  Avatars/<source category>/<avatar>/<avatar>.rocketbox.json
  Animations/<static|xy|xyz>/<clip>.glb
  Animations/<static|xy|xyz>/<clip>.rocketbox.json
  Garments/<top|bottom|shoes|hair>/<candidate>.glb
  LICENSES/Microsoft-Rocketbox-MIT.md
```

Every released binary is paired with provenance that records the original
repository path and commit, source and derived SHA-256 hashes, converter
revision, license, skeleton/texture facts, and its production runtime URL.
Generated binaries are stored through Git LFS. The production authority is
Seeker's external MadeHuman asset store; the netdisk copy under
`datasets/makehuman/public-assets` is the durable backup. Git LFS is a portable
release mirror, not the serving dependency.

Avatar conversion preserves Rocketbox skin weights, embeds the source TGA
material graph as PNG images, and normalizes the body subset onto the canonical
MadeHuman 67-bone names and parent graph. Rocketbox facial bones and morphs are
retained as extras where present.

Garment extraction is conservative. Loose pieces are accepted only from exact
source edge-connectivity. Fused clothing requires multi-view semantic evidence
projected onto visible source faces, with unseen labels propagated only through
the indexed surface graph. Candidates must pass a no-skin visual review,
orientation review, MadeHuman try-on fit, and animated penetration review
before entering the sandbox wardrobe catalog.
